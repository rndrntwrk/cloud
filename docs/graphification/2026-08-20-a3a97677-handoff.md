## Architecture captured

- Next.js control plane spans identity, organizations, agents, conversations, models, credits, payments, containers and MCP.
- RuntimeFactory constructs/caches AgentRuntime by agent and organization.
- CreditsService and container creation use row locks and transactional ledger writes.
- MCP uses lazy HTTP connections and per-entity context where available.
- Writes route to NA primary; EU may use a logical read replica.
- Secrets use AES-256-GCM envelope encryption with AWS KMS.

## Incorrect mappings or integrations

- Crypto payment confirmation opens a nested credit transaction, allowing payment rollback after committed credits.
- x402 verifies independently supplied payload/requirements without complete signed challenge binding.
- API keys are stored plaintext as well as hashed.
- MCP and container-health URLs bypass the existing SSRF validator.
- A fixed development API key creates a synthetic paid identity.
- ERC-2612 permit and transfer are separate transactions.
- Do not assume Cloud Eliza runtime compatibility without pinning the Eliza package/fork version.
